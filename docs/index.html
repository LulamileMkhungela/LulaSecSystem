1. Overview

LulaSecSystem is a unified security operations platform that brings together incident management, visitor tracking, patrol monitoring, AI surveillance, access control, and real-time dispatch into a single, role-aware application.

It is designed to scale from a single guard post to a multi-site enterprise, with five pre-configured user roles that each get a tailored dashboard and feature set.

Why LulaSecSystem?

  • Unified One platform, one login, all security operations
  • Role-aware Every user sees only what's relevant to their job
  • Real-time Live maps, live feeds, live updates
  • AI-augmented Threat scoring, anomaly detection, smart alerts
  • Mobile-ready Panic button works from any device

2. Quick Start

  1. Open index.html in a modern browser (Chrome, Edge, Firefox, Safari)
  2. Click 🚀 Launch the App on the landing page, OR pick a role from the 👁️ Try a Demo Account modal
  3. You'll be signed in instantly with pre-filled credentials
  4. Explore the role-specific dashboard from the sidebar
  5. Try clicking the red 🆘 PANIC button (top-right) to see the emergency dispatch flow

No backend required — the entire demo runs in your browser with realistic mock data.

4. User Roles & Permissions

🛡️ Administrator Full access

The top-of-the-pyramid role. Administrators manage the entire platform: users, sites, policies, integrations, and global analytics.

Sidebar modules:
  • 📊 Dashboard, 🗺️ Live Map, 🚨 Incidents, 👮 Guards & Patrols, 🪪 Visitors, 📹 Cameras, 🔐 Access Control, 📈 Analytics, 👥 User Management, ⚙️ Settings

🎯 Security Officer Operational

Manages day-to-day operations for an assigned site or region. Triages incidents, dispatches guards, runs live surveillance, and produces reports.

Sidebar modules:
  • 🎯 Command Center, 🗺️ Live Map, 🚨 Incidents, 👮 Guard Force, 🪪 Visitors, 📹 Cameras, 📈 Reports, 📡 Dispatch

👮 Security Guard Field

The boots-on-the-ground role. Guards run patrols, scan checkpoints, submit incident reports, talk to dispatch, and trigger the panic button when needed.

Sidebar modules:
  • 🏠 My Dashboard, 🚶 My Patrol, 🚨 Report Incident, 🪪 Visitor Check-in, 📞 Communications, 🎓 Training

🏠 Resident Community

Lives in a LulaSec-protected estate or building. Pre-registers guests, reports neighborhood issues, and participates in community watch.

Sidebar modules:
  • 🏠 My Home, 🪪 Pre-Register Guest, 🚨 Report Issue, 👥 Community Watch, 🔔 Notifications, 👤 My Profile

🪪 Visitor Limited

A pre-registered guest with view-only access to their own visit pass and host details. Can show their QR code at the gate.

Sidebar modules:
  • 🎫 My Visit, 🪪 My Pass

5. Features by Module

📊 Dashboard

Each role has a customized dashboard:

  • Admin: Cross-site KPIs, incident trends, site status, recent notifications
  • Officer: Triage queue, response time, force status
  • Guard: Shift timer, checkpoint progress, quick actions, performance rating
  • Resident: Estate status, expected guests, packages, announcements
  • Visitor: QR pass, visit details, host info

🚨 Incident Management

  • Report new incidents with type, severity, site, zone, and description
  • View all incidents with status tabs (All, Open, In Progress, Resolved, Closed)
  • Click any incident to see full details, AI threat score, and evidence
  • Reassign, resolve, or close incidents from the detail view
  • AI Threat Score (0-100) auto-calculated and color-coded

🪪 Visitor Management

  • Pre-register visitors with ID, host, purpose, and vehicle
  • Auto-generated pass code (e.g., VST-A4821)
  • One-click check-in and check-out
  • Track all visitor history and current status

👮 Guard & Patrol Management

  • View all guards with current status, location, shift
  • Track patrol completion percentage with progress bars
  • Performance ratings (1-5 stars)
  • Click any guard to see detailed profile and quick-call

📹 Camera Surveillance

  • Grid of all cameras with live "scan-line" animation
  • Online/offline status, AI detection status, alert counts
  • Click any camera for full-screen view with controls
  • AI alerts integrated into the incident system

🔐 Access Control

  • Manage doors, vehicle gates, and secure zones
  • Lock/unlock remotely with one click
  • Multi-factor modes (Card, Biometric, PIN, ANPR)
  • User counts and last access times

📈 Analytics & Reports

  • Incident trends (bar chart) over last 7 days
  • Incidents by type (donut chart)
  • Response time trend (line chart) over 7 months
  • Key performance metrics: response time, resolution rate, performance score

6. Innovative Features

🆘 One-Tap Panic Button

Available in the top bar of every page. Click it to:

  • Immediately alert dispatch with your live GPS
  • Stream live audio from your device
  • See the ETA of the responding unit in real time
  • Cancel within 10 seconds if it's a false alarm

🤖 AI Threat Scoring

Every incident gets a 0-100 threat score with explainable reasoning. Scores above 70 trigger immediate dispatch recommendations.

🗺️ Live Operations Map

A geo-aware map showing all guards, incidents, cameras, and visitors on a single screen — with animated pulses for active events.

🗣️ Voice Dispatch

Push-to-talk between dispatchers and field guards, with real-time transcription for record-keeping.

🌗 Dark / Light Theme

Toggle the theme with the moon/sun button in the top bar. Preference is saved across sessions.

⌘K Quick Search

Press ⌘K (or Ctrl+K) anywhere to jump to the search bar.

7. Common Workflows

Reporting an incident (Guard)

  1. Click 🚨 Report in the top bar (or sidebar)
  2. Fill in title, type, severity, site, zone, description
  3. Submit — a notification fires to all admins/officers

Pre-registering a visitor (Resident)

  1. Click 🪪 Pre-Register Guest
  2. Enter name, ID, purpose, vehicle
  3. Receive auto-generated pass code
  4. Forward the pass code to your guest for seamless entry

Triage an incident (Officer)

  1. From the dashboard, view the incident queue
  2. Click an incident to see full details + threat score
  3. Reassign to an available guard
  4. Mark as resolved when complete

9. Technical Architecture

LulaSecSystem is built as a zero-dependency, vanilla-JS single-page application for maximum portability and zero install friction.

File structure

LulaSecSystem/
├── index.html          # Main entry point + landing + app shell
├── css/
│   └── styles.css      # Complete design system
├── js/
│   ├── data.js         # In-memory mock database (users, sites, incidents, etc.)
│   ├── auth.js         # Session & login logic
│   └── app.js          # Pages, routing, event handlers, charts
├── assets/
│   └── favicon.svg
└── docs/
    └── index.html      # This documentation

Tech stack

  • UI: Pure HTML5 + CSS3 (custom design system, no framework)
  • Logic: Vanilla JavaScript (ES2020+), no build step
  • Charts: Inline SVG (no charting library needed)
  • State: In-memory + sessionStorage + localStorage
  • Fonts: Inter (UI) + JetBrains Mono (codes)

Browser support

Chrome 90+, Edge 90+, Firefox 88+, Safari 14+. Mobile browsers fully supported.
